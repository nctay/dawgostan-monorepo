# Issue tracker: GitHub

Specs and implementation tickets live in GitHub Issues for nctay/dawgostan-monorepo. Use gh from this checkout.

- Read the complete issue and comments before working.
- Create issues using --body-file for multiline Markdown; apply ready-for-agent to approved implementation tickets.
- Add native blocked-by relationships using the blocking issue's numeric database ID. If the API is unavailable, record blocking issue links in the body and report the fallback.
- Work only on tickets whose blockers are complete.
- PRs as a request surface: no.
